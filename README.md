# Witcher 3 Remaster to Next-Gen Converter

This program converts save files from version 5.0 (the remastered version) to 4.04 (also known as 'Next-Gen').

The converter only changes what version 4.04 needs. It updates the version information, removes data that
only version 5.0 uses, and adjusts the inventory to the older layout.

Because the skill tree in the remaster
is too different it also does:

**1. reset your skills and gives back all your skill points, so you can spend them again.**  

**2. put back equipped mutagens into your inventory.**  

*Everything else, such as your quest progress and your
items, stays as it was.*  

(So far I haven't had issues with it, but if you find any,
let met know)  

-------------------------------
### Before doing anything, back up your saves!
------------------------------

After you have converted your save, loaded it in-game and confirmed everything is how it should be, overwrite or make a save while on 4.04 so the game
can do it's thing and create a better structured save.

***Most of the code here was generated by an LLM***
