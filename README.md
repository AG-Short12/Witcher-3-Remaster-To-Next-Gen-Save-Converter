# Witcher 3 Remaster to Next-Gen Converter

This program converts save files from version 5.0 (the remastered version) to 4.04 (also known as 'Next-Gen').

The converter only changes what version 4.04 needs. It updates the version information, removes data that
only version 5.0 uses, and adjusts the inventory to the older layout.

Because the skill tree in the remaster
is too different it also does:  
  
**1. reset your skills and gives back all your skill points, so you can spend them again.**  

**2. put back equipped mutagens into your inventory.**  

*Everything else, such as your quest progress and your
items, stays as it was.*  

(So far I haven't had issues with it, but if you find any,
let me know)

### Before doing anything, back up your saves!
------------------------------

### How to run

**On Windows**

Download `w3-downgrade-[version]-win.exe` from the
[Releases](https://github.com/AG07-Alexander-Gel/Witcher-3-Remaster-To-Next-Gen-Converter/releases) page
and double-click it. You do not need to install Python. If Windows warns you about an unknown program,
choose "More info" and then "Run anyway".

**With Python**

You need Python 3.12 or newer. Download this repository, open a terminal in its folder, and run:

```
python -m pip install -r requirements.txt
python w3_downgrade_app.py
```

### **Converting a save**

1. Choose your save with the first Browse button. Your saves are usually in
   `Documents\The Witcher 3\gamesaves`.
2. Choose an output folder. It has to be a different folder than the one your save is in.
3. Leave the skill template empty and press "Convert to 4.04".
4. Copy the new `.sav` file and its `.png` picture from the output folder into your save folder.

After you have converted your save, loaded it in-game and confirmed everything is how it should be, overwrite or make a save while on 4.04 so the game
can do its thing and create a better structured save-file.

### How to build

You can build `w3-downgrade.exe` yourself on Windows. You need Python 3.12 or newer. Open a terminal in
this repository's folder and run:

```
python -m pip install -r requirements-build.txt
python build.py
```

The finished program is in the `dist` folder.
