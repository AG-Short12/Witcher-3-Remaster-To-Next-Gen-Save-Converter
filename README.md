# Witcher 3 Remaster to Next-Gen Converter

This program converts save files from version 5.0 to 4.04 (also known as 'Next-Gen).

The converter only changes what version 4.04 needs. It updates the version information, removes data that
only version 5.0 uses, and adjusts the inventory to the older layout. Because the skill tree in version 5.0
is different. 

What it does extra:

1. It resets your skills and gives back all your skill points, so you can spend them again.  

2. Equipped mutagens go back into your inventory. 

Everything else, such as your quest progress and your
items, stays as it was.
